Загрузите все файлы из этой папки в корень репозитория GitHub. В Settings → Pages включите публикацию из main / root. Откройте ссылку GitHub Pages в Safari на iPhone → Поделиться → На экран «Домой». Распознавание файлов через Claude вне Claude недоступно; ручной ввод и генерация Word остаются. Для первоначальной установки требуется интернет.
